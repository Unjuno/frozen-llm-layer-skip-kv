### 変更記録のひな型

```markdown
### D-XXX: 変更の題名
- 日付:
- 状態: 確定 / 提案 / 保留 / 棄却
- 変更前:
- 変更後:
- 根拠: （データ・数式・一次文献・実装制約）
- 影響範囲: （文書・比較実験・再測定の要否）
```

**確認：** この一覧は「何を採用して研究するか」という仕様の履歴であり、実験済み・性能達成済みの証拠ではない。
