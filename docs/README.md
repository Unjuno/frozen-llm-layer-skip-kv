## 読み方：設計と成果を混同しない

| ラベル | 意味 |
|---|---|
| **確定仕様** | この研究で採用すると明示された前提 |
| **実装候補** | 最初に試す方法。比較や実験で変更し得る |
| **仮説** | 実験で反証できる主張。成功は未確認 |
| **未決** | 実験前に決定・記録する必要がある条件 |
| **検証済み** | 再現条件と測定証拠が保存されて初めて使う表記 |

## 最短で全体像を理解する

1. [研究目的とモデル構造](01_FOUNDATIONS.md)で、何を変えないかを確認する。
2. [Router学習](02_ROUTER_TRAINING.md)で、生成中の全層マスク探索と更新方法を読む。
3. [KV補完](03_KV_CACHE.md)で、どの状態を保存し、いつ補完するかを確認する。
4. [評価設計](04_EVALUATION.md)で、どの比較がどの仮説を検証するか読む。
5. [検証ゲート](05_GATES.md)で、次に実装・判断すべきことを確認する。

**単一の数学的仕様を複数ファイルへコピーしない。** 関連文書からは参照リンクを張る。期限ではなくGateの合否で進める。
