# 14｜初段Attention活性による実行領域選択：新規性Pilot（2026-11-26）

**結論：UNCERTAIN（動的選択の優位性は未実証）。** 事前学習済みQwen3-0.6BでHeadの生成報酬学習は動作したが、今回の短い評価では全層実行に退化。別の同一層数診断では経路間のNLL差が存在したものの、初段Attentionの線形読み出しが固定経路を上回らなかった。

## 先行研究と反証

[出典台帳 RW-18〜21](PRIOR_ART_AND_ATTRIBUTION.md)を参照。DiffSkip (ACL 2025) はAttention変化量によるFFN選択、Dr.LLM (arXiv:2510.12773, Table 6) は入力Embeddingと各層特徴の比較、PoLar (ICML 2026) とその追試 (arXiv:2609.31360) は入力別経路の選択利益と強い固定経路との区別、HeRo (arXiv:2609.08189) は層をまたぐ履歴の価値を扱う。本研究の差分候補は**第1Attentionで計算済みの文脈依存活性を再利用する単一Linear Headから、トークン別の全中間層実行マスクを一括出力すること**。網羅的な新規性確認ではない。

## Pilot B: 同一トークン・同一層数での線形読み出し診断

[実行コード](../experiments/qwen3/probe_early_activation.py) ／ [実測JSON](../results/qwen3_early_activation_probe_cpu_2026-11-26.json)

同じ実モデル・FP32・CPU 2スレッド。学習6問、比較4問（学習と異なるプロンプト）。各問の正解回答の先頭部分を教師強制し、**現在トークンを空白1個（ID 220）に固定**。3候補は事前指定し、すべて第1・最終層を含む25/28ブロックを実行（Eager KV）。候補Aのskip層（1-based）は5,13,21、Bは8,16,24、Cは11,19,26。次の正解トークンのNLLを比較。正解は学習ラベル／評価用であり推論時のHead入力には含めない。線形ridge読み出し（正則化0.1、学習データのみで中心化・適合）は補助診断であり、本来の26-bitオンポリシー学習を置き換えない。

**重要な反証：** 学習6問ではAの平均NLL 1.700426、B 1.735093、C 3.637902。比較4問ではBがAより大幅に良く、Oracleとの差はわずか0.000123。従ってOracleと学習側最良固定Aの差を動的適応の価値と解釈するのは誤り。今回の3候補では、事後固定BだけでほぼOracleに到達した。初段活性による動的選択の利益は観測できなかった。

実行層数一致はGPU時間・FLOPs一致の証明ではない。1問1位置の教師強制NLLは自己回帰生成の正解率と異なる。候補集合が小さく、比較4問も公開デバッグ用で既に一部を別のPilotで評価済み。一般的な表現力の否定も、新規性の肯定もできない。

## 次の実験（実施条件）

- Nativeで正解が得られる問題・十分な生成長を先に確定する。正解評価器と書式条件を固定し、文字列類似度だけで誤答を学習成功としない。
- 学習・開発・最終評価の独立集合を確保。複数固定マスクを開発集合だけで探索して選択し、同一の計算予算で動的選択と比較する。
- 同一予算診断ではEmbedding／Attention活性／第1Block出力／固定・ランダム選択を比較し、候補集合・正則化・閾値を最終評価前に固定する。事後最良固定とOracleの差も報告し、動的選択自体に価値があるかを診断する。
- 生成学習は26-bit単一Linear Headのみという主構造を保持。複数seed、探索と決定的評価の実行率差、マスク退化、実GPU時間とVRAMを別途評価。
